⚠ DATA PROVENANCE. No Binance WebSocket is attached. Every trade, depth observation, wall, absorption event, latency sample and price below is produced by a local synthetic feed adapter (regime-driven). The adapter sits behind one normalization boundary (Adapter.onTrade / onDepth / onBookTicker / onKline) so it can be replaced by solusdt@depth@100ms · solusdt@aggTrade · solusdt@bookTicker · solusdt@kline_1m without touching collectors, metrics or the state machine. Confluence points are not a calibrated probability and this build must not be used to evaluate signal quality — that requires recorded live depth/trade history. Nothing here is randomized per frame: all displayed metrics are computed from collected events.
